1. Каков главный фокус роли Product Manager (PdM) в IT-команде?
Верно!
PdM отвечает за бизнес-составляющую и вопрос «Что и зачем мы строим?». Сроками же занимается PM.
Ошибка.
PdM сфокусирован на ценности продукта и потребностях пользователей. Управление сроками — задача Project Manager.
2. Какого специалиста называют «мостом» между бизнесом и технической командой разработки?
Точно!
Аналитики переводят «хотелки» бизнеса на язык технических требований (ТЗ), понятный разработчикам.
Не совсем.
Эту роль выполняют аналитики. Они формализуют требования бизнеса в технические задания.
3. Чем занимается Backend Developer в процессе создания приложения?
Правильно!
Backend — это «мозг» под капотом, скрытый от пользователя, где происходят все расчеты и хранение данных.
Нет.
Backend-разработчик отвечает за серверную часть, базы данных и API. Интерфейсом занимается Frontend.
4. В чем главное отличие UX-дизайнера от UI-дизайнера?
Именно так!
UX (Experience) — про удобство и сценарии, UI (Interface) — про эстетику, цвета и кнопки.
Ошибка.
UX — это User Experience (опыт, логика), а UI — это User Interface (внешний вид).
5. Какова основная задача DevOps-инженера?
Верно!
DevOps связывает разработку (Dev) и эксплуатацию (Ops), обеспечивая быстрый и стабильный релиз.
Неверно.
DevOps настраивает инфраструктуру, автоматизирует деплой (выкладку) кода и следит за работой серверов.
6. Зачем в банковских проектах нужен Information Security Specialist?
Да!
В финтехе безопасность критична: защита транзакций и персональных данных — приоритет №1.
Ошибка.
Безопасник защищает систему от взломов и следит за соблюдением стандартов (например, ФЗ-152).
7. Реальный кейс: Кто создает API для функции оплаты мобильной связи?
Верно!
API — это технический интерфейс взаимодействия программ. Его пишет бэкенд, чтобы фронтенд мог отправить запрос на оплату.
Неверно.
API — это задача Backend-разработчика. Фронтенд лишь «дергает» (использует) это API.
8. Какова роль Project Manager (PM) в цепочке создания функции?
Браво!
PM — это дирижер оркестра. Он делает так, чтобы все роли сработали синхронно и продукт вышел вовремя.
Ошибочка.
PM координирует команду, управляет коммуникациями и устраняет блокеры, чтобы проект двигался по плану.
